## 方法论沉淀

1. **修正顺序 (Kai 纠正)**: 从管线末端往上游推——先在消费端定谳 prompt 层真伪,
   失真镜反推上游叙事层漏采;勿从 P00 顺依赖链往下猜
2. **主方法 (Kai 定案)**: T4 渲染回测——首尾帧钉原片+prompt 描述+H3 预览渲染+
   同位对比,渲染一致=prompt 对
3. **T2 往返的定位**: 血缘预检工具+低成本烟雾,不是定谳工具
4. **ASR 全文阅读 > 抽帧**: 决定性证据是通读 ASR 尾段,抽帧只是辅助;
   先读文本再选帧,别先抽帧猜
5. 定谳权在视频证据,管线只是探针——防止金标退化成管线的镜子
