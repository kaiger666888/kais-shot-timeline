| Threat ID | Category | Component | Disposition | Mitigation Plan |

Belt-and-suspenders. |
| T-06-SC | Tampering | pip/npm/cargo installs | accept | Plan 01 adds ZERO new packages — only stdlib (`json`, `os`, `inspect`) + existing `jsonschema` (v1.0 baseline). No install tasks; slopcheck/package-legitimacy gate trivially satisfied. |
