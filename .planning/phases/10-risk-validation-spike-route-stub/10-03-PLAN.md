  <decision>Which macro-F1 methodology should the SER spike use given that ep01 has no ground-truth emotion labels? (AF-02/AF-03 forbid fabricating rigorous F1.)</decision>
  <context>RESEARCH §Pitfall 4 + Assumption A3 + VALIDATION.md Manual-Only Verifications all flag this as a plan-time decision. The choice affects how run_ser_sensevoice.py computes the macro-F1 number that gates the DIA-04 ≥50%/40-50%/<40% threshold. Without user confirmation, the spike cannot honestly report a single gating number.</context>
  <options>
    <option id="methodology-a">
      <name>(a) Self-consistency + qualitative review (PRIMARY — zero extra labor)</name>
      <pros>Zero developer labor; runs SenseVoice N=3 times with slightly different VAD segmentations, measures how often the emotion label agrees with itself across runs; report calls result a "self-consistency index" or "calibrated estimate", NOT "F1"; aligns with the report's "calibrated estimate" grep-gate requirement.</pros>
      <cons>Measures precision (label stability), NOT accuracy (correctness). A model that always predicts NEUTRAL would score 100% self-consistency but 0% actual accuracy on non-NEUTRAL dialogue. AF-02/AF-03 caveat becomes more prominent.</cons>
    </option>
    <option id="methodology-b">
      <name>(b) Developer-annotated 30-segment stratified sample (~1hr labor, MORE rigorous)</name>
      <pros>True macro-F1 against human labels on the SAME 30 stratified segments. Meets the report's threshold language ("macro-F1 ≥50%") most literally. Strongest evidence for DIA-04 ship/defer.</pros>
      <cons>~1 hour of manual labor labeling 30 segments with HAPPY/SAD/ANGRY/NEUTRAL/FEARFUL/DISGUSTED/SURPRISED. Subject to annotator bias (developer is not a trained emotion rater). 30-segment sample is small for 7-class macro-F1 (avg ~4 samples/class).</cons>
    </option>
    <option id="methodology-c">
      <name>(c) Benchmark-only F1 on RAVDESS-test (cross-domain proxy)</name>
      <pros>Published ground truth; results directly comparable to literature; no ep01 manual labor.</pros>
      <cons>Tests English speech, NOT Chinese animation dialogue — does not actually answer the DIA-04 cross-domain question. Defeats the purpose of the spike (the whole point is to measure the RAVDESS→中文动画 gap). Report would need an extra caveat that the number is benchmark-only.</cons>
    </option>
    <option id="methodology-ab">
      <name>(a+b) Hybrid — run (a) first, THEN optional (b) if (a) is ambiguous</name>
      <pros>Defers the manual-labor decision until the cheap experiment shows whether the result is borderline (40-50%). If (a) gives clear ≥50% or <40%, skip (b).</pros>
      <cons>Two-stage analysis; report must clearly explain the staged methodology.</cons>
    </option>
  </options>
