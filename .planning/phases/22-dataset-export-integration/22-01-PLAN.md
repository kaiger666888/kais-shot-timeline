roundtrip.json sidecar（ep01 实测，19 镜全冻结）：
- 顶层 {"schema_version": "1.3", "shots": [...]}；每 shot keys = shot_id / regen / scores / verdict（status 仅失败镜在场）

- scores.midframe_sim keys: score / model；scores.judge keys: attribution（enum: prompt_faithful | model_diverged | prompt_underspecified）/ confidence / reason
- verdict keys: decision（accepted|rejected）/ source（auto|human）/ decided_at

prompts.json：顶层是**平铺 list**，entry keys = shot_id / start_sec / end_sec / duration / prompt_text / subject / action / camera / scene / lighting / style（character_refs/prop_refs 为可选键，ep01 缺席 → 面板显示 `(无)`；无 prompt_version 键——版本从 sidecar regen.prompt_version 取）。

shots.json：list，entry keys = **id**（非 shot_id）/ start_sec / end_sec / duration——与 sidecar 的 shot_id 对齐用 int 相等。

生成器形态契约（UI-SPEC 锁定）：单文件 self-contained（CSS/JS/data 全 inline，外部资源仅 2 个 `<video>` src 相对路径）；CLI = --roundtrip / --video / --shots / --prompts / --tau-sim（默认 0.9670）/ --output；原子写 tmp + os.replace；收尾 print `[roundtrip-review] wrote <path> (N shots)`；html/ 是 namespace package——`_esc` 必须**内联**（禁跨文件 import，gen_registry_review.py:83-84 docstring 明文）。

XSS 三层（SC3 硬要求，逐字来源见 22-PATTERNS §XSS three-layer hardening）：
1. `_esc(s)`：str() 兜底后 5 字符转义 &amp; &lt; &gt; &quot; &#x27;（& 先）；强制清单 = judge.reason / attribution（enum 也转）/ verdict.decision+source / status.error / midframe_sim.model / engine_name+engine_version+prompt_version / prompt_text + 全部六 facet / character_refs+prop_refs / asset_name；数字先 str()
2. bootstrap：`json.dumps(payload, ensure_ascii=False).replace("</", "<\\/")`
3. JS 动态更新一律 classList/textContent，零 innerHTML
