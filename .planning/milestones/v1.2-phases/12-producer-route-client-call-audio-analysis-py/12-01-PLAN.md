## Schema contract (Phase 11 — the client's pre-write validation target)

Target: `spec/schemas/audio_semantic.schema.json` (Draft 2020-12, additionalProperties:false)
Top-level: `{"schema_version":"1.2", "word_level_experimental":<bool>, "shots":[...]}`
  - schema_version: required string, pattern `^(0|[1-9]\d*)(\.(0|[1-9]\d*))?$`
  - word_level_experimental: optional bool — true IFF any shot.dialogue.words[] non-empty
  - shots[]: required array; each item requires only `shot_id` (int ≥1); all else optional

Phase-10-informed field shape rules (PROJECT.md Key Decisions + audio_semantic.schema.json $comment):
  - dialogue.emotion: `type:["string","null"]` (NOT enum — SenseVoice self_consistency is label-stability proxy, NOT calibrated accuracy). Paired with emotion_confidence `type:["number","null"]` range [0,1].
  - dialogue.words[]: EXPERIMENTAL — `{start,end,text,score?}`; only emit when route returns word-level align (WhisperX). Top-level word_level_experimental MUST be true if any words present.
  - instruments field: OMITTED entirely (MUS-04 deferred v1.3 — MERT has no classifier head, PANNs zenodo-blocked). The literal "instrument" MUST NOT appear in the client file (case-insensitive English grep returns 0 — Phase 11 schema $comment lock).
  - sfx: `{events:["BGM","Applause",...], description:"<NL>"}` — SenseVoice non-speech events only (PANNs 527-class deferred).
  - reproduction: `{tts,music_gen,foley}` each `{$ref repro_prompt}` — Phase 12 passes through whatever the route returns; Phase 15 owns recomposition. Absent modality → null or omitted.
